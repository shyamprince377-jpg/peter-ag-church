# PETER AG CHURCH Website

## Files
- index.html — complete homepage
- style.css — responsive design
- script.js — mobile menu, buttons, toast messages, active navigation

## How to run
1. Keep all three files in the same folder.
2. Open `index.html` in Chrome/Edge/Firefox.
3. For publishing, upload the three files to any static hosting service.

## Customize
Search these placeholders in `index.html` / `script.js`:
- Phone / WhatsApp number
- Address
- YouTube link
- Worship timings
- Church description
- Song/message links

The demo uses online Unsplash images for the visual sections. Replace those URLs with your own church photos for the final website.
